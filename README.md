# Pastebin Lite

A simple web application to save and share text snippets online. Users can create pastes via a form, which are stored in a database and viewable through unique URLs.

---

## **Features**
- Save text snippets to a local database.
- View pastes via unique URLs.
- Minimalistic and lightweight design.
- Built for learning and experimentation.

---

## **Languages & Tools**
- **Languages:** JavaScript, HTML  
- **Tools/Libraries:** Node.js, Express.js, SQLite3, npm
